
# TaskFlow — видение продукта

## Видение
TaskFlow — это программа-планировщик задач для людей, у которых
много дел и которые боятся забыть о дедлайнах.

Какую проблему решает: программа заранее напоминает о будущих
задачах и дедлайнах, а также информирует о времени важных событий.
Благодаря этому человек успевает отреагировать на срочные дела
заблаговременно, а не тогда, когда срок уже прошёл.

Отличие от бумажного списка: задачи не потеряются — список
сохраняется в файл, его не нужно искать и носить с собой, а
программа сама напомнит о просроченных задачах.

## Функциональные требования
1. Система должна позволять создать задачу с названием.
2. Система должна позволять изменить задачу.
3. Система должна позволять удалить задачу.
4. Система должна позволять назначить задаче приоритет (1–3).
5. Система должна позволять указать дату выполнения задачи.
6. Система должна позволять добавить задаче один или несколько тегов.
7. Система должна сохранять список задач в файл.
8. Система должна загружать список задач из файла при запуске.
9. Система должна находить задачи по тегу.
10. Система должна находить задачи по дате.
11. Система должна находить задачи по приоритету.
12. Система должна показывать список задач, отсортированный по дате.

 ## Нефункциональные требования
1. Система должна работать в консоли Windows.
2. Данные должны храниться в текстовом файле формата CSV.
3. Программа должна запускаться не дольше 3 секунд.

## Глоссарий
**Задача** — запись с названием, датой, приоритетом и тегами.
**Тег** — короткая метка для группировки задач (например, «учёба»).
**Приоритет** — число от 1 до 3: чем меньше, тем важнее.
**Актор** — тот, кто взаимодействует с системой.
**Вариант использования** — цель пользователя, выраженная как действие.
**MVP** — минимальная версия продукта, которая уже полезна.
**CSV** — текстовый формат, где значения разделены запятыми.
**Include** — обязательное включение одного варианта в другой.
**Extend** — необязательное расширение варианта.
**Обобщение** — связь «общий — частный».
