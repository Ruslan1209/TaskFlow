# Обоснование решений ДЗ-3 (TaskFlow)

## Почему у задачи такие состояния

- **Новая** — задача только добавлена в список, работа ещё не началась.
- **В работе** — пользователь начал выполнять задачу.
- **Приостановлена** — пользователь отложил работу; задача не потеряна, но не двигается.
- **Просрочена** — срок прошёл, а задача не выполнена. Отдельное состояние нужно,
  потому что такая задача ведёт себя иначе: её нельзя приостановить, только
  выполнить или отправить в архив.
- **Выполнена** — работа закончена, зафиксирована дата выполнения.
- **Отменена** — пользователь решил задачу не делать.
- **В архиве** — конечное хранилище: задача больше не показывается в активном списке.

«В работе» и «Приостановлена» объединены в составное состояние **Активна**:
у них одинаковое поведение по отношению к отмене, выполнению и проверке срока.

## Запрещённые переходы и почему

| Откуда | Куда | Почему запрещён |
|---|---|---|
| Новая | Выполнена | нельзя завершить задачу, не начав её: markDone() работает только из «В работе», «Приостановлена» и «Просрочена» |
| Новая | В архиве | архив — место для завершённых и отменённых задач; новую нужно сначала отменить или выполнить |
| Выполнена | Отменена | выполненную задачу нельзя отменить — результат уже есть; cancel() возвращает false |
| Выполнена | В работе | повторное выполнение не предусмотрено; чтобы переделать работу, создаётся новая задача |
| В архиве | любое состояние | архив конечен: start(), pause(), markDone() из него не работают |
**Разрешённый неочевидный переход: «Просрочена» → «В работе»** — метод `start(today)`. Просроченную задачу можно переоткрыть и продолжить работу: срок прошёл, но сама задача ещё актуальна. На «восстановление» она переходит, а вот приостановить просроченную нельзя — `pause()` работает только из «В работе». Запрет на возврат в работу оставлен только для завершённых состояний: из «Выполненной» и «Архивной» задача в работу не возвращается — там работа уже закончена, и `start()` не имеет смысла.

Сторожевое условие **[срок прошёл]** стоит на переходе check(today): если today
позже даты задачи, статус становится «Просрочена». Условие **[дата не в прошлом]**
стоит на переходе start() из «Новой»: задачу с прошедшей датой начать нельзя —
её можно только отменить.
