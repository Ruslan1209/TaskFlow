# TaskFlow — оглавление UML-диаграмм проекта (ДЗ-1 — ДЗ-4)

Список всех диаграмм экзаменационного проекта TaskFlow. Каждая строка: название — файл — что показывает.

## Диаграммы ДЗ-1
- **Диаграмма вариантов использования** — `uml/01_usecase.png`. Что пользователь и таймер напоминаний могут делать в TaskFlow: добавить, найти, отметить, сохранить задачи, получить напоминание.

## Диаграммы ДЗ-2
- **Диаграмма классов (предметная область)** — `uml/02_class_domain.png`. Все классы TaskFlow и отношения между ними: композиция, агрегация, обобщение, зависимость, ассоциация, реализация. *Обновлена в ДЗ-4: добавлены Menu и TaskService.*

## Диаграммы ДЗ-3
- **Диаграмма состояний задачи** — `uml/03_state_task.png`. Жизненный цикл задачи: создана → активна → выполнена (и возврат, если задачу переоткрыли).
- **Диаграмма деятельности** — `uml/03_activity_add.png`. Процесс «Добавить задачу»: действия, решения и потоки от ввода данных до сохранения.
- **Черновик диаграммы последовательности** — `uml/03_seq_add_draft.png`. Первый черновик сценария «Добавить задачу», исправлен в ДЗ-4.

## Диаграммы ДЗ-4
- **Последовательность «Добавить задачу»** — `uml/04_seq_add.png`. Полный сценарий от меню до сохранения с веткой alt: данные верные / ошибка проверки.
- **Последовательность «Найти задачи»** — `uml/04_seq_search.png`. Поиск по критериям: loop по задачам и alt «найдено / ничего не найдено».
- **Последовательность «Сохранить и загрузить список»** — `uml/04_seq_save.png`. Работа с файлом: alt «файл открылся / ошибка» и временное ограничение сохранения.
- **Кооперация «Добавить задачу»** — `uml/04_communication_add.png`. Те же объекты и сообщения с нумерацией 1, 1.1–1.4 и условием в квадратных скобках.
- **Компонентная диаграмма** — `uml/04_component.png`. Крупные части программы (меню, ядро, хранилище, уведомления) и два интерфейса: ITaskStorage, ITaskPrinter.
- **Диаграмма развертывания** — `uml/04_deployment.png`. TaskFlow работает на одном компьютере; артефакты: исполняемый файл, tasks.csv, settings.ini; по желанию — облачная синхронизация по HTTPS.
