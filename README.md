# TaskFlow — менеджер задач на C++

Консольное приложение для ведения списка задач с типами задач,
приоритетами, тегами и сохранением в файл.

Автор: Мусин Руслан, группа ПВ621.

## Сборка

Проект — заголовочный C++ (только `.h`-файлы и один `main.cpp`).
Компиляция любой стандартной командой, например:

g++ -std=c++17 src/main.cpp -o planner

text

## Запуск

./planner

text

## Как пользоваться

После запуска доступно меню:

- 1 — добавить задачу (тип: обычная / со сроком / повторяющаяся,
  название, описание, приоритет 1–3, дата для задач со сроком,
  интервал для повторяющихся, теги через запятую)
- 2 — показать все задачи
- 3 — изменить задачу по номеру (Enter — оставить старое значение)
- 4 — удалить задачу по номеру
- 5 — сохранить список в файл
- 6 — загрузить список из файла
- 7 — настройки (формат хранения txt/csv, путь к файлу;
  выбор запоминается и восстанавливается при следующем запуске)
- 8 — поиск по тегу, дате и/или приоритету (Enter — пропустить критерий)
- 9 — создать задачу из шаблона (Prototype): «Еженедельный отчёт»
  или «Оплатить счёт»; создаётся глубокая копия шаблона — изменение
  тегов у копии не затрагивает шаблон
- 10 — импорт задач из внешнего списка (Adapter): LegacyTodoAdapter
  переводит данные «чужой» библиотеки LegacyTodo в задачи проекта
  (приоритет 0–9 → 1–3, unix-срок → дата ГГГГ-ММ-ДД)
- 0 — выход

## Где что хранится

- Файл задач — путь задаётся в настройках (по умолчанию `tasks.txt`).
- Файл настроек — `settings.txt`, создаётся автоматически
  при первом изменении настроек.

## Структура проекта

- `src/` — исходный код (заголовки + main.cpp)
- `uml/` — диаграммы (`.puml` и отрисованные `.png`)
- `docs/` — документация: `PATTERNS.md`, `05_why.md`, `06_why.md`, `UML_README.md`

## Использованные паттерны

- **Singleton** — AppSettings (настройки), TaskFactory (реестр типов задач)
- **Factory Method** — TaskCreator и три конкретных создателя типов задач
- **Abstract Factory** — IStorageFactory: семейства хранилищ txt и csv
- **Builder** — TaskBuilder: пошаговая сборка задачи с валидацией в build()
- **Prototype** — Task::clone() и реестр шаблонов TaskTemplates
- **Facade** — TaskFlowFacade: единственная точка входа для main.cpp
- **Adapter** — LegacyTodoAdapter: импорт из «чужой» библиотеки LegacyTodo

Подробности — в `docs/PATTERNS.md`, `docs/05_why.md` и `docs/06_why.md`.
